# Global agent memory (SSOT)

## Typography

- Use plain dashes (-) only. Never use em-dashes; they create a robotic fingerprint in professional communication.

## Git integrity

- Never auto-add the agent's name as a co-author.

## Technical weights

- Prioritize quality, simplicity, and maintainability.
- Do not over-weight development cost (agents often overestimate human dev time).

## Bug reproduction

- Always start with a reproduction in an end-to-end setting.

## Excellence

- Fix unrelated lint errors, pixel-misalignments, or test flakiness encountered during the task.

## Automation safety

- Never manually modify changelog.md or any files marked as autogenerated.
